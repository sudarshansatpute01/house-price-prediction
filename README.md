\# House Price Prediction (Beginner ML Project)



\## Overview

This project predicts house prices using a simple Linear Regression model.  

Features: Size (sq ft), Bedrooms, Age.  

Target: Price.



\## Steps

1\. Load dataset (`data.csv`).

2\. Split into training and testing sets.

3\. Train a Linear Regression model.

4\. Evaluate predictions vs actual prices.

5\. Visualize results with a scatter plot.

6\. Test custom predictions.
